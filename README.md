## Multi-Trip Last-Mile Vehicle Routing with Driver Workload Balancing

This project studies a last-mile delivery problem in which each vehicle can perform more than one trip during the planning horizon. In many urban delivery systems, a vehicle does not complete only one long route. Instead, it may leave the depot, serve a group of customers, return to the depot for reloading, and then start another trip. This structure is especially useful when vehicle capacity is limited or when many customers must be served within the same day.
In this problem, each customer must be visited exactly once by one of the available vehicles. Each vehicle can perform multiple trips, but every trip must start and end at the depot. The model must consider vehicle capacity, customer demand, route duration limits, and the total working time of each driver. In addition to minimizing total transportation cost, the problem also aims to balance the workload among drivers so that one driver is not assigned significantly more work than the others.
The main decisions are how to assign customers to vehicles, how to divide each vehicle’s work into multiple trips, and how to sequence the customers within each trip. The objective is to minimize total travel cost while also penalizing workload imbalance among drivers. Workload can be measured using total travel time, total service time, number of customers served, or total working time.
Students will first formulate the mathematical model under deterministic assumptions, where customer demands, service times, travel times, and vehicle capacities are known in advance. Then, they will develop a Genetic Algorithm to construct feasible multi-trip routes, split customer sequences into trips, and evaluate both routing cost and workload balance. Since the problem combines routing, trip partitioning, capacity constraints, and fairness among drivers, exact methods may become difficult for larger instances, making a Genetic Algorithm a suitable solution approach.
In the summer phase, the project will focus only on mathematical modeling and Genetic Algorithm development, without machine learning. In a later stage, the same problem can be extended by using machine learning to predict route duration, estimate workload imbalance, suggest promising trip partitions, or improve the fitness evaluation of the Genetic Algorithm. This makes the project suitable as both a last-mile routing optimization study and a foundation for future learning-augmented delivery planning research.
